EDGAR — La Base de Données de la SEC
Naviguer sur EDGAR comme un professionnel — L'outil gratuit le plus puissant du trader
La plupart des traders débutants ne connaissent pas EDGAR. C'est l'erreur la plus coûteuse qu'ils
font. EDGAR contient TOUTE la vérité sur chaque entreprise cotée aux USA — et c'est entièrement
gratuit. Ce chapitre te transforme en lecteur professionnel de SEC filings.
Qu'est-ce qu'EDGAR ?
I Définition
EDGAR (Electronic Data Gathering, Analysis, and Retrieval) est la base de données officielle de la
SEC.
Toute entreprise cotée aux USA doit déposer ses documents légaux et financiers sur EDGAR.
Ces documents sont publics, gratuits, accessibles à tous : toi, les hedge funds, les analystes — tout le
monde.
Adresse : www.sec.gov/cgi-bin/browse-edgar
I Analogie
EDGAR, c'est comme le casier judiciaire d'une entreprise.
Tout ce qu'elle a fait, tout ce qu'elle doit, tous ses résultats, tous ses problèmes — tout y est.
Un investisseur qui n'utilise pas EDGAR trade à l'aveugle.
Un investisseur qui utilise EDGAR voit ce que la plupart des autres ne voient pas.

Comment naviguer sur EDGAR
1
Aller sur www.sec.gov La page d'accueil de la SEC. Chercher
'EDGAR Full-Text Search' ou 'Company Search'.
M
2
Chercher par ticker ou nom Dans 'Company Search', entrer le ticker
(ex : AAPL pour Apple) ou le nom de l'entreprise. Choisir le bon
résultat.
M
3
Sélectionner le type de filing Filtrer par type : 10-K (annuel), 10-Q
(trimestriel), 4 (insiders), 8-K (événements), etc. Ou laisser 'All' pour
tout voir.
M
4
Lire le document Cliquer sur la date du filing pour ouvrir. Les gros
documents ont une table des matières. Utiliser Ctrl+F pour chercher
des mots-clés précis.
M
5
Utiliser la recherche full-text EDGAR Full-Text Search permet de
chercher un mot-clé dans TOUS les documents SEC. Ex : chercher
'ATM program' pour trouver tous les ATM actifs.

II En pratique
URL directe pour Apple :
https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK;=AAPL&type;=10-K
Pour chercher les Form 4 récents d'une entreprise : filter par type '4'
Pour trouver un ATM program : chercher 'S-3' ou '424B3' dans les filings récents
Raccourci clavier dans EDGAR : Ctrl+F → taper 'risk factor' ou 'ATM' ou 'warrant' pour trouver les
sections clés
I Bon à savoir
Sites alternatifs qui lisent EDGAR plus facilement :
Macrotrends.net : graphiques financiers basés sur les SEC filings
OpenInsider.com : agrège les Form 4 des insiders
WhaleWisdom.com : agrège les 13F des hedge funds
SEC.gov/cgi-bin/viewer : viewer amélioré pour les XBRL filings

II Attention
Ne jamais trader une action dont tu n'as pas vérifié les filings récents.
Un S-3 actif + ATM program = l'entreprise peut diluer à tout moment pendant ton trade.
Un NT 10-K sur une small cap = signal d'alarme sérieux — problème comptable possible.
Un Form 4 avec achat massif d'un CEO = souvent le meilleur signal d'entrée long.
I À retenir
EDGAR = base de données gratuite de la SEC = toute la vérité sur chaque entreprise cotée.
La routine matinale : 8-K + Form 4 + NT filings + 424B avant chaque séance.
Utiliser EDGAR Full-Text Search pour trouver des mots-clés précis ('ATM', 'warrant', 'dilution').
Sites complémentaires : OpenInsider.com, WhaleWisdom.com, Macrotrends.net
I Pour mémoriser
EDGAR = www.sec.gov → Company Search → Ticker → Filtrer par type
Routine : 8-K (news) + Form 4 (insiders) + S-3/424B (dilution) = chaque matin avant 9h30
Full-Text Search = chercher 'ATM' ou 'warrant' dans tous les documents en même temps
