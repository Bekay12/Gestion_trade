# Brown & Brown, Inc. — Anlageanalyse

LaTeX-Quelle einer belegpflichtigen Unternehmensanalyse aus Primärdokumenten
(SEC-Einreichungen). Keine Prüfungsleistung: das Dokument dient der eigenen
Anlageentscheidung. Jede Zahl ist gegen die gedruckte Seite ihrer Quelle geprüft.

```bash
./build.sh          # -> out/analyse.pdf
```
