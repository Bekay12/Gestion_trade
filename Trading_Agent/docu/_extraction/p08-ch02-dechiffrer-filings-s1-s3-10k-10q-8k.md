Le S-1 — Le Prospectus d'IPO

Le S-1 est le document qu'une entreprise doit déposer à la SEC avant son IPO.
C'est le document le plus complet et le plus important qu'une entreprise publiera jamais.
Il contient TOUT : la vérité sur les risques, les finances, le management, la structure du capital.

Trouver un S-1 sur EDGAR : Company Search → Ticker → Type 'S-1'

Le S-3 — Autorisation de Vendre des Actions Supplémentaires
I Définition
Le S-3 est le formulaire qui autorise une entreprise DÉJÀ cotée à émettre et vendre des titres
supplémentaires.
C'est l'autorisation légale nécessaire pour un ATM program, un PIPE, ou toute nouvelle émission
d'actions.
Un S-3 actif signifie que l'entreprise PEUT diluer ses actionnaires à tout moment.
II Attention
Un S-3 récent sur EDGAR = l'entreprise s'apprête potentiellement à lever des fonds.
L'équation dangereuse : S-3 actif + cours en hausse + small cap = ATM probable en cours.
Toujours vérifier si un S-3 est actif avant d'acheter une small cap en mouvement haussier.
Le montant maximal autorisé dans le S-3 te dit combien l'entreprise peut diluer.
II En pratique
Sur EDGAR : chercher 'S-3' dans les filings récents de l'entreprise
Lire la section 'Shelf Offering' pour connaître le montant autorisé
Un S-3 de 50M$ sur une entreprise à 30M$ de market cap = peut doubler le nombre d'actions
Le 20-F — Rapport Annuel des Entreprises Étrangères
I Définition
Le 20-F est l'équivalent du 10-K pour les entreprises étrangères cotées aux USA via des ADR.
Il suit les normes comptables internationales (IFRS) plutôt que les normes américaines (US GAAP).
Déposé annuellement, il contient les mêmes informations qu'un 10-K.

II En pratique
Ne pas lire tout le 10-K — trop long. Priorité : Risk Factors + MD&A; + Cash Flow Statement
Comparer le 10-K de cette année avec celui de l'année précédente : quels nouveaux Risk Factors
sont apparus ?
Chercher 'going concern' dans le 10-K : si présent = l'auditeur doute de la survie de l'entreprise →
signal extrêmement négatif
Chercher 'material weakness' dans Item 9A : problème de contrôle interne = risque de fraude ou
d'erreur comptable

Moins détaillé que le 10-K mais contient les chiffres à jour.
3 trimestres par an (le 4e est couvert par le 10-K annuel).

Le NT 10-K / NT 10-Q — Signal d'Alarme
I Définition
NT = Notification of Late Filing. L'entreprise demande un délai supplémentaire pour déposer son 10-K
ou 10-Q.
Elle a jusqu'à 15 jours supplémentaires pour un 10-Q et 15 jours pour un 10-K.
II Attention
Un NT 10-K ou NT 10-Q est un signal d'alarme sérieux.
Raisons légitimes : comptabilité complexe, changement d'auditeur, acquisition récente.
Raisons inquiétantes : problème de contrôle interne, désaccord avec l'auditeur, potentiel restatement.
Règle : si une small cap dépose un NT → vérifier immédiatement les raisons dans le document.
Si la raison est vague ou liée à des 'enquêtes internes' → signal de vente fort.
Le 8-K — Les Annonces qui Font Bouger les Marchés
I Définition
Le 8-K est le rapport d'événement courant. Une entreprise doit le déposer dans les 4 jours ouvrables
suivant tout événement 'matériel'.
C'est le document qui fait bouger les cours en temps réel — les algorithmes le lisent en millisecondes.

II En pratique
Configurer des alertes SEC sur EDGAR pour tes positions : 'SEC Filing Alerts'
Site utile : SECAlerts.com ou Stockanalysis.com → alertes 8-K par email ou SMS
Lire le 8-K en entier : le titre peut être trompeur — les détails négatifs sont souvent enfouis
Un 8-K déposé un vendredi soir = mauvaise nouvelle cachée pour minimiser l'impact → ouvre en gap
down lundi
I Bon à savoir
Stratégie des insiders : déposer les mauvaises nouvelles le vendredi soir après 16h.
Raison : les médias et analystes ne le couvriront pas avant lundi matin.
Le marché n'y réagira qu'à l'ouverture lundi → gap down moins visible sur les charts hebdomadaires.
Règle : toujours vérifier les 8-K du vendredi soir sur tes positions avant le lundi matin.
I À retenir
S-1 = prospectus IPO → lire Risk Factors + Use of Proceeds en priorité.
S-3 = autorisation de dilution → si actif sur une small cap = danger.
10-K = rapport annuel complet → chercher 'going concern' et 'material weakness'.
10-Q = rapport trimestriel → comparer les marges sur 4 trimestres.
NT = retard de dépôt → signal d'alarme → vérifier les raisons.
8-K = événement courant → fait bouger les cours → configurer des alertes.
I Pour mémoriser
S-1 = IPO document | S-3 = autorisation dilution | 20-F = étranger
10-K = annuel (90 jours) | 10-Q = trimestriel (45 jours) | NT = retard = signal d'alarme
8-K = news importantes dans les 4 jours → vendredi soir = mauvaise nouvelle cachée
Mots-clés à chercher : 'going concern' + 'material weakness' + 'ATM' + 'warrant'
